AquaPredict-IoT

IoT-Based Smart Irrigation System Using Predictive Soil Moisture Models

This repository contains the electronic design, software, and technical documentation developed for the AquaPredict-IoT research project.

The system integrates an ESP32 microcontroller, soil moisture and environmental sensors, MQTT communication, automated irrigation control, and predictive soil moisture models.

Project Structure

Hardware: Altium Designer schematics, PCB files, and component libraries.

Documentation: Electronic diagrams and technical references.

Firmware: ESP32 programming and control logic.

Python: Data acquisition, processing, and predictive modelling.

Development Status

Electronic schematic development is currently in progress.
